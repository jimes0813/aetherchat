# AetherChat Computer Use

> 平台说明：文档读写和 Electron 截图支持 Windows 与 Linux。本文下述 UI Automation、窗口控制和键鼠注入仅适用于 Windows；Linux 版本会在 `/desktop/status` 中将这些能力标记为不可用。

AetherChat 采用与 Codex 同类的“观察 → 动作 → 再观察”闭环。模型不是只生成一段鼠标脚本：它先取得窗口截图和 Windows UI Automation 无障碍树，选择窗口、元素或坐标执行动作，再读取新的状态验证结果。单次请求最多执行 12 轮，用户可随时用“中断全部”停止。

## 模型可用动作

内置 `desktop-control` 插件 2.0 向模型提供以下工具：

- 列出应用与可见窗口，包括窗口 ID、进程和屏幕边界；
- 观察整个虚拟桌面或指定窗口，返回 PNG 截图、`snapshot_id` 和最多 300 个可索引无障碍元素；
- 激活窗口，按 `snapshot_id + element_index` 或窗口相对坐标点击；
- 输入 Unicode 文本、发送 Ctrl/Shift/Alt/Win 组合键、设置输入框值；
- 水平/垂直滚动、拖拽；
- 启动已存在的 `.exe` 或 `.lnk`，不接受命令行参数；
- 浏览本机目录，读取或写入受支持文档。

截图不会写入工具日志中的 JSON；它会作为视觉输入单独送回支持图像的模型。文本工具结果和动作状态也会送回模型，因此模型能根据实际结果继续，而不是在第一次工具调用后结束。

## 本机授权

模型首次请求 Computer Use 时，后端会通过一个仅绑定 `127.0.0.1`、使用随机令牌认证的私有通道请求 Electron 主进程显示原生确认框。默认按钮是拒绝。用户可以：

- 只允许当前动作；
- 允许当前 AetherChat 进程内的 Computer Use 会话；
- 拒绝。

会话授权只在当前进程内存中保存，退出应用即失效。任意本机文档写入和启动应用仍始终逐次确认。每个模型工具调用都会进入 AetherChat 工具运行日志；输入文本和文档正文在审计参数中只记录长度或“已脱敏”，不保存原文。

## 文件与文档

手动“电脑”面板继续使用 Windows 原生文件对话框和不透明文件句柄。模型工具可在用户确认后按路径访问下列格式：

| 格式 | 可用操作 | 重要限制 |
| --- | --- | --- |
| `.txt` / `.md` / `.json` / `.csv` / `.tsv` | 读取和文本写入 | 文本编辑上限 5 MB |
| `.docx` | 编辑段落文字和现有表格单元格 | 不是完整 Word 引擎；复杂修订、图表、文本框和页眉页脚不在编辑范围内 |
| `.xlsx` | 编辑工作表单元格值和公式字符串 | 每表最多 500×100；不计算公式，不支持宏 |
| `.pptx` | 编辑现有幻灯片中的文本形状 | 不编辑图片、图表、动画、母版或备注 |
| `.pdf` | 提取文本，改标题/作者/主题，可追加备注页 | **不能直接重写原 PDF 页面的文字、图片或版式** |

覆盖原文档默认先创建带时间戳的 `*.aetherchat-backup-*` 备份，再以临时文件、`fsync` 和原子替换写入。单文件通用上限为 50 MB；UNC/设备路径和 NTFS 备用数据流被拒绝。

## 安全边界

```text
模型工具调用
    ↓
AetherChat 后端（动作校验、12 轮上限、审计）
    ↓  私有 loopback + 随机 consent token
Electron 主进程原生授权
    ↓
Windows UI Automation / 截图 / SendInput / 文档服务
    ↓
新截图与无障碍状态返回模型
```

- Renderer 启用 `contextIsolation`、Chromium sandbox，关闭 Node.js 集成；桌面令牌和授权令牌不暴露给 Renderer 或模型。
- 窗口元素索引只对最近一次、15 分钟内的 `snapshot_id` 有效，且必须属于同一窗口。
- 坐标必须位于 Windows 虚拟桌面边界内；点击次数、滚动量、拖拽时长、文本长度和快照数量均有限制。
- 多模型同时请求 Computer Use 时会串行执行，避免两个模型同时争夺键鼠。
- 自定义声明式插件不能声明 Python/JavaScript/命令执行处理器，不能借插件安装绕过内置授权层。

这些措施不是 Windows 账户隔离。AetherChat 以当前用户权限运行；允许会话控制后，模型能看到并操作该账户当前可访问的界面。不要以管理员身份运行普通会话，也不要在包含密码、付款、发送或删除操作的界面盲目批准。

Windows 打包依赖和发布检查见 [WINDOWS_PACKAGING.md](../frontend/WINDOWS_PACKAGING.md)。
